# ART VPN

ART VPN — Android-клиент для публичных VLESS-конфигураций из подборок белых списков РФ. Приложение загружает свежие списки, отбрасывает несовместимые конфигурации, проверяет TCP-доступность, а при подключении **проверяет реальный HTTPS-трафик через VPN и автоматически перебирает резервные узлы**.

## Что изменено в версии 0.2.0

- Вместо одного мобильного файла объединяются мобильная подборка и полный список WHITE-CIDR-RU-all.
- Два списка запрашиваются одновременно; для каждого списка зеркала проверяются параллельно, первый корректный ответ принимается сразу. Тайм-аут загрузки ограничен, медленные зеркала не перебираются одно за другим.
- Проверка TCP выполняется параллельно для 48 наиболее перспективных узлов, чтобы длинные списки не задерживали запуск.
- Неподдерживаемые конфигурации отбрасываются до показа в интерфейсе. В частности, sing-box 1.14.x не поддерживает XHTTP transport; TCP-открытый XHTTP-узел не считается пригодным сервером.
- TCP-проверка защищает диагностические сокеты от попадания в свой же VPN.
- Подключение больше не заканчивается на успешном запуске sing-box: приложение одновременно проверяет несколько независимых HTTPS-адресов через поднятый туннель. Неудачные узлы запоминаются и временно опускаются в рейтинге, успешные получают приоритет.
- Автоподбор проверяет до пяти лучших кандидатов. Подключение можно отменить большой центральной кнопкой.
- IPv4 и IPv6 маршруты включены в TUN.
- Узел, который прошёл реальную проверку VPN-трафика, запоминается и получает приоритет при следующем подключении.

## Источники

Основной upstream: [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia).

Используются:
- Vless-Reality-White-Lists-Rus-Mobile.txt
- WHITE-CIDR-RU-all.txt

Upstream публикует обновления ориентировочно каждые 2–4 часа, а также описывает собственную проверку конфигураций перед публикацией. Это не гарантирует доступность конкретного узла на каждом операторе или в каждом регионе. Список публичных серверов меняется; реальная проверка производится на устройстве пользователя.

## Интерфейс и простота использования

Главный экран содержит одну большую кнопку: нажмите её для подключения или отключения. Выбор серверов и ручное обновление скрыты в дополнительном разделе, чтобы не перегружать интерфейс.

## Важные ограничения

- В этой версии поддерживается VLESS с TCP, TLS/Reality, WebSocket, gRPC, HTTP и HTTPUpgrade транспортами, в рамках возможностей встроенного sing-box.
- XHTTP, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC пока не включены в селектор серверов. Не показываем узлы, которые текущий движок не умеет запускать.
- Метка «TCP» означает только открытый TCP-порт. «VPN OK» появляется только после успешного HTTPS-запроса через действующий VPN-туннель.
- Скорость измеряется отдельно после подключения и зависит от сети, времени суток и тестового сервера.
- Общедоступные конфигурации могут перестать работать в любой момент; приложение не может гарантировать постоянную доступность бесплатных сторонних серверов.

## Сборка

Требуются JDK 17 и Android SDK 35. В корне проекта:

```bash
gradle :app:assembleDebug --no-daemon
```

APK: app/build/outputs/apk/debug/app-debug.apk.

GitHub Actions собирает arm64 APK и автоматически публикует prerelease в разделе [Releases](https://github.com/graf1tyy/art_whitewpn/releases).

## Технологии и лицензии

- Kotlin + Jetpack Compose
- Android VpnService
- sing-box libbox 1.14.4
