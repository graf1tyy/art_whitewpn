# ART VPN 0.4.5

ART VPN — минималистичный Android VPN-клиент на Kotlin и sing-box. Он автоматически собирает публичные VLESS-конфигурации из нескольких поддерживаемых источников, отбирает совместимые узлы и проверяет подключение настоящим HTTPS-трафиком через VPN-туннель.

## Что умеет версия 0.4.5

- Загружает основную мобильную подборку и полный список белых IP/CIDR из upstream-проекта igareck.
- Дополняет её отдельным обновляемым RU/CIS VLESS-списком из kort0881. Этот источник сам агрегирует публичные проекты; ART VPN не загружает все протоколы из его общей коллекции.
- Зеркала одного источника запрашиваются параллельно. Медленное зеркало не блокирует остальные.
- Удаляет дубликаты и отбрасывает некорректные UUID, неизвестные транспорты и неподдерживаемые flow.
- Выполняет быстрый TCP-отбор ограниченного числа перспективных узлов. Открытый порт — это только предварительный признак, не доказательство работы VPN.
- Во время подключения запускает VLESS через sing-box и проверяет реальный HTTPS-трафик через поднятый Android VPN-туннель. После неудачи автоматически пробует следующий кандидат.
- Успешные и неудачные подключения запоминаются. Успешные узлы получают приоритет; временно неудачные опускаются в рейтинге.

## Учет мобильного оператора

На мобильной сети приложение определяет активный тип подключения и доступный Android идентификатор оператора. История успешных и неудачных узлов хранится локально на телефоне отдельно для каждого оператора.

- Один неудачный запуск не исключает сервер.
- После двух недавних неудач на том же операторе узел временно опускается в рейтинге на 30 минут.
- Успех на конкретном операторе повышает приоритет этого узла именно для него.
- Ошибка на одном операторе не переносится автоматически на другого.
- При подключении через Wi-Fi используется отдельный локальный Wi-Fi-профиль; его неудачи не понижают серверы для мобильных операторов.

Для этого не запрашиваются геолокация, контакты или доступ к звонкам. Если Android не предоставляет данные оператора, приложение использует отдельный профиль неизвестной мобильной сети. Оператор сам по себе не позволяет заранее достоверно предсказать блокировку в конкретном регионе или на конкретной базовой станции, поэтому окончательное решение принимает проверка реального трафика на устройстве.

## Источники конфигураций

- [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia) — мобильная VLESS-подборка и WHITE-CIDR-RU-all.
- [kort0881/vpn-vless-configs-russia](https://github.com/kort0881/vpn-vless-configs-russia) — дополнительная подборка VLESS RU/CIS с SNI-фильтрацией.

Список конфигураций постоянно меняется. Доступность публичного узла зависит от оператора, региона, текущей блокировки, состояния сервера и его владельца. Ни размер списка, ни TCP ping не гарантируют подключение.

## Интерфейс

Главный экран рассчитан на использование в одно касание: большая центральная кнопка подключает или отключает VPN. Технические сведения и список серверов скрыты в дополнительном разделе.

## Поддерживаемые конфигурации

В текущей сборке поддерживаются VLESS с TCP, TLS/Reality, WebSocket, gRPC, HTTP и HTTPUpgrade в рамках встроенного sing-box 1.14.4.

XHTTP, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC пока не включены в подборщик. Такие записи не должны попадать в список кандидатов. Поддерживается только flow `xtls-rprx-vision` или пустой flow.

## Важные замечания

- «TCP доступен» означает только то, что удалось открыть TCP-порт.
- Рабочим сервер считается только после успешного HTTPS-запроса через активный VPN-туннель.
- Публичные серверы управляются третьими лицами. Их владельцы потенциально могут наблюдать метаданные и незашифрованный трафик; не используйте неизвестные бесплатные узлы для банковских операций и особо чувствительных данных.
- Постоянная доступность бесплатных конфигураций не гарантируется.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.9:

```bash
gradle :app:assembleDebug --no-daemon
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions собирает arm64 APK и публикует prerelease в [Releases](https://github.com/graf1tyy/art_whitewpn/releases).
