# ART VPN

Минималистичный Android VPN-клиент: получает публичные конфигурации для белых списков РФ, проверяет доступность узлов, помогает выбрать лучший сервер и подключает устройство через sing-box.

## Идея

1. ART VPN загружает актуальные конфигурации из публичных подписок.
2. Список кэшируется на устройстве; ошибка обновления не удаляет последний рабочий список.
3. Узлы проверяются отдельно на TCP-доступность и задержку.
4. Пользователь видит страну, протокол и ping. Реальная пропускная способность отображается во время активного VPN-сеанса, а не подменяется результатом TCP-пинга.
5. Подключение работает через Android `VpnService` и встроенный sing-box (`libbox`).

## Источники конфигураций

Основной источник: [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia).

- `Vless-Reality-White-Lists-Rus-Mobile.txt` — мобильная подборка.
- `WHITE-CIDR-RU-all.txt` — расширенный список.

Для доступности предусмотрены зеркала GitHub, GitLab и Codeberg. Приложение обновляет подписки вручную при открытии/по кнопке и в фоне примерно раз в 4 часа.

Конфигурации являются сторонними и недоверенными данными. Перед подключением ART VPN проверяет формат и ограничивает размер загружаемого списка. Публичные узлы могут исчезать, менять владельца или вести себя нестабильно; доступность не гарантируется.

## Сборка

Требуются Android Studio и JDK 17.

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions также собирает debug APK и публикует его как workflow artifact.

## Технологии

- Kotlin + Jetpack Compose
- Android `VpnService`
- sing-box `libbox`
- OkHttp и WorkManager
